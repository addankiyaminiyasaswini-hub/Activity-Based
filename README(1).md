## Projects

### Case 1: Personal Portfolio Website
A personal website designed to present:
- Profile and educational qualifications
- Technical skills and hobbies
- Projects and achievements
- Resume and contact information
- Responsive layouts, CSS animations, and interactive navigation

### Case 20: Restaurant and Cafe Website
A restaurant website designed to present:
- Menu sections and chef profiles
- Restaurant ambience and customer testimonials
- Opening hours and location details
- A table reservation form
- Responsive menus and elegant typography

### Case 26: College Fest Management Website
A college festival website designed to present:
- Technical events and cultural competitions
- Workshops and event schedules
- Event coordinators and rules
- Registration forms
- Category-based cards and responsive event banners

## Project Structure

Keep the files for each website in the project folder. If you use a landing page to access all three websites, you can organize the files like this:

```text
project-folder/
├── index.html
├── case1.html
├── case20.html
├── case26.html
├── README.md
└── assets/
    └── images/
```

> The structure above is a suggested organization. Adjust filenames and folders to match the files in your project.

## How to Run

1. Download or clone the project folder.
2. Make sure the HTML files and any image/CSS/JavaScript assets remain in their expected locations.
3. Open `index.html` in a web browser if it is available.
4. Select a website link or preview from the landing page to open that website.
5. If there is no landing page, open `case1.html`, `case20.html`, or `case26.html` directly.

## Technologies

- **HTML** — website structure
- **CSS** — styling, layout, responsiveness, and animations
- **JavaScript** — include only if used in the project

## Notes

- Keep image paths and filenames unchanged unless you update their references in the HTML.
- Test the pages in a browser and check that navigation links and forms work as expected.
- A form's visual appearance does not necessarily mean it stores or submits data; this depends on its implementation.
